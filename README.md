# 마라톤 코스 모아보기 & 교통 정보

2026년 11~12월 서울에서 열리는 마라톤 대회의 코스와 교통통제 정보를 한 화면에서 보여주는 웹페이지

## 로컬에서 실행하기

브라우저에서 `index.html`을 바로 열면 CSV를 읽지 못하므로 간단한 서버를 띄워서 확인한다.

```bash
# 저장소 최상위 폴더에서 실행
python -m http.server 8000
```

브라우저에서 http://localhost:8000/web/ 접속

서버 종료는 터미널에서 `Ctrl + C`

## 폴더 구조

```
01_marathon_crawling.ipynb   마라톤 온라인 대회 목록 크롤링
data/                        대회·코스 데이터
web/                         웹페이지 (index.html, style.css, app.js)
```

## 데이터

### marathons_raw.csv

마라톤 온라인(roadrun.co.kr)에서 수집한 서울 대회 목록 (40개)

| 칼럼 | 내용 |
|---|---|
| 번호 | 마라톤 온라인 대회 번호 (다른 파일과 연결하는 키) |
| 대회명, 대회일시, 날짜 | 대회 이름과 일정 (`날짜`는 YYYY-MM-DD) |
| 대회종목, 대회장소 | 종목 (예: 하프,10km,5km)과 집결 장소 |
| 주최단체, 홈페이지 등 | 대회 상세 정보 |
| 교통통제 | 1 = 서울시 광역 교통통제 대상, 0 = 해당 없음 |

### waypoints.csv

대회별 코스 경유지 병합본. 지도에 코스를 그릴 때 사용한다.

| 칼럼 | 내용 |
|---|---|
| 대회번호 | marathons_raw.csv의 `번호`와 같음 |
| 대회명, 종목 | 대회 이름과 종목 |
| 순서 | 종목 안에서 지나가는 순서 |
| 경유지명 | 지점 이름 |
| 구분 | 출발 / 경유 / 반환 / 도착 (코스가 없는 대회는 코스정보없음, 대회취소) |
| 위도, 경도 | 좌표 |
| 출처 | 코스 정보를 가져온 페이지 |
| 비고 | 2회전, 편도 코스 등 |

`waypoint_2-9.csv` ~ `waypoints_33-40.csv`는 팀원별로 나눠서 수집한 원본이고, 이를 합친 것이 `waypoints.csv`
