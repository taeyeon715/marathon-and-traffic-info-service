# 마라톤 코스 모아보기 & 교통 정보

2026년 11~12월 서울에서 열리는 마라톤 대회의 코스와 교통통제 정보를 한 화면에서 보여주는 웹페이지

## 로컬에서 실행하기

```bash
# 저장소 최상위 폴더에서 실행
pip install -r requirements.txt   # 처음 한 번만
streamlit run app.py
```

브라우저가 자동으로 열림 (안 열리면 http://localhost:8501 접속)

코드를 저장하면 브라우저 오른쪽 위 `Rerun`을 눌러 바로 확인 가능, 종료는 터미널에서 `Ctrl + C`

## 폴더 구조

```
01_marathon_crawling.ipynb   마라톤 온라인 대회 목록 크롤링
data/                        대회·코스 데이터
app.py                       전체 화면 배치 (제목, 월 선택, 각 파트 불러오기)
race_list.py                 대회 목록
course_map.py                코스 지도
traffic.py                   교통통제 정보
faq.py                       자주 묻는 질문
```

## 데이터

### marathons_raw.csv

마라톤 온라인(roadrun.co.kr)에서 수집한 서울 대회 목록 (40개)

| 칼럼 | 내용 |
|---|---|
| 번호 | 마라톤 온라인 대회 번호 (다른 파일과 연결하는 키) |
| 대회명, 대회일시, 날짜 | 대회 이름과 일정 (`날짜`는 YYYY-MM-DD) |
| 대회종목, 대회장소 | 종목 (예: 하프,10km,5km)과 집결 장소 |
| 주최단체, 홈페이지 등 | 대회 상세 정보 |
| 교통통제 | 1 = 서울시 광역 교통통제 대상, 0 = 해당 없음 |

### waypoints.csv

대회별 코스 경유지 병합본. 지도에 코스를 그릴 때 사용한다.

| 칼럼 | 내용 |
|---|---|
| 대회번호 | marathons_raw.csv의 `번호`와 같음 |
| 대회명, 종목 | 대회 이름과 종목 |
| 순서 | 종목 안에서 지나가는 순서 |
| 경유지명 | 지점 이름 |
| 구분 | 출발 / 경유 / 반환 / 도착 (코스가 없는 대회는 코스정보없음, 대회취소) |
| 위도, 경도 | 좌표 |
| 출처 | 코스 정보를 가져온 페이지 |
| 비고 | 2회전, 편도 코스 등 |

`waypoint_2-9.csv` ~ `waypoints_33-40.csv`는 팀원별로 나눠서 수집한 원본이고, 이를 합친 것이 `waypoints.csv`

## 역할 분담

| 이름 | 파트 | 작업 위치 |
|---|---|---|
| 건우 | 코스 지도: 선택한 대회의 경유지를 folium 지도에 선과 마커(출발·반환·도착)로 표시 | `course_map.py` |
| 하진 | 교통통제 정보: 통제 대회의 구간·시간 정리, 12월 서울시 공지 나오면 `교통통제` 값 갱신 | `traffic.py` |
| 예린 | 대회 목록: 표 정렬·검색, 종목/교통통제 필터, 취소·코스 없는 대회 표시 | `race_list.py` |
| 서영 | 자주 묻는 질문 + 디자인: 질문 버튼과 답변 작성, 화면 꾸미기 | `faq.py` |
